# Blog writing context

When creating, revising, or reviewing articles under `content/posts/`, first read:

- `knowledge/README.md`
- `knowledge/blog-structure.md`
- `knowledge/blog-style-guide.md`

These documents describe this repository's article structure and reusable writing styles. Follow the user's current request first. Style codes A–D are writing presets, not values for the article's `type` field.

Use the requested style when specified. Otherwise infer it from the subject and existing material; ask only if a choice would materially change the result. Preserve verified personal details, keep technical claims precise, and avoid expanding an article with repetitive qualifications.

Keep writing guidance in `knowledge/`, outside the public `content/` collection. If the user names an external knowledge base, confirm the actual destination and successful write before reporting an upload.
