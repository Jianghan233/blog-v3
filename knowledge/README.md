# 博客写作知识库

这套资料用于下次写作时快速选风格、沿用结构，不是博客正文。它从现有文章提炼，再结合本次“理顺逻辑、减少字数”的要求整理；建议字数和风格代号是写作约定，不是已经实现的网站配置。

| 选择教程、排障、叙事或复盘风格 | [博客风格指南](blog-style-guide.md) |

下次可以直接这样说：

> 参考 knowledge/blog-style-guide.md，用 A「实践教程」写这篇，保留一点吐槽，步骤紧凑，控制在 2000 字左右。

> 用 C「生活叙事」改这份记录，按时间推进，不编对话，结尾停在真实感受上。

> 用 D「赛后复盘」整理素材，重点讲失误原因和下次怎么练，故事和分析各占一半。
